# 2026-08-25 気象データのLLM構築 進捗

## 今日やったこと
- Ollama(ローカルLLM, qwen2.5:7b)を使った気象データ分析プロトタイプ `analyze_weather.py` を作成
- v1: 集計データをそのままLLMに渡す方式 → コンテキスト長不足で数値を捏造するバグを発見・修正
- v2: 具体的な数値(℃・mm・m/s)は一切LLMに渡さず、コードが直接出力。LLMには都市間の順位関係と異常時刻だけを渡し、定性的な解釈・比較のみを書かせる設計に変更 → 数値捏造は構造的に解消
- 出力を自動検証する仕組み(数値+単位の出現チェック)を実装

## わかったこと・次の課題

- 「小規模ローカルLLMがどこまで正確で、どこから怪しくなるか」を実験で切り分けられた
- 次の課題: 順位・関係性の読み違えを自動検出する仕組み、より大きいモデル(14B級以上)との比較
